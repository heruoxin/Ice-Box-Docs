現在のバージョン番号とチャネルの情報は、Ice Box の「Settings」＞「About」画面で確認できます。各配布チャネルの説明と最新版 APK のダウンロードについては、[ダウンロードページ](/download/#channels)をご覧ください。

## 3.9.2 {#v3-9-2}

- target API を 26 に更新。Android の要件により、バックグラウンドで動作するアプリは必ず通知を表示する必要があります。そのため、「Auto Freeze」などバックグラウンドでの動作が必要な機能をオンにしていると、通知領域に通知が必ず表示されます。この通知は端末のシステム設定でオフにでき、機能には影響しません

- 以前のベータ版で、非 root モードを開けないことがある問題を修正
- 起動時にまれにアプリが表示されなくなる問題を修正
- データベースを変更
- Island アプリの API を更新
- その他の更新とバグ修正

## 3.9.0 {#v3-9-0}

- 安全に凍結できるシステムアプリのリストを共有する機能を追加：
一部の端末の ROM には、不要なプリインストールアプリや広告が多く含まれています。多くのユーザーは、それらを 1 つずつ凍結して整理しています。
こうした作業に詳しい方は、凍結済みのプリインストールアプリのリストをほかの人と共有したり、次に ROM を書き換えるときのために保存しておいたりできます。
（リストの作成機能は、一部のアクティブなユーザーにのみ公開しています）

- QR コード認識機能を追加：
Ice Box を再度有効化するときに、長い注文番号を手入力する必要はありません。Alipay の取引明細画面のスクリーンショットを撮って共有し、共有先で「Barcode recognition」（Ice Box のコード認識）を選ぶだけで、読み取って有効化できます。

- 作成できるタブ数の上限を撤廃
