## 結論 {#answer}

そのアプリを凍結しましょう。凍結したアプリは動作できないため、バックグラウンドで自動起動したり常駐したりすることも、裏でバッテリーやデータ通信量を消費することもありません。Ice Box ならワンタップでまとめて凍結でき、使いたいときはタップするだけで解凍して起動できます。使い終わったら、自動で凍結し直すこともできます。Ice Box は root 化した端末にも、していない端末にも対応しています。

## アプリがバックグラウンドで動作するのはなぜ？ {#why}

多くのアプリは、長いあいだ開いていなくても、端末の起動時、ネットワークへの接続時、充電時、プッシュ通知の受信時などに自動で起動します。Android の「強制停止」で止められるのはその 1 回だけで、アプリはそのあとまた自動で起動できます。

凍結の場合は違います。アプリを凍結すると、Ice Box で解凍するまで、システムがそのアプリを起動することはありません。

## Ice Box でバックグラウンド動作を止める手順 {#steps}

1. [Ice Box をダウンロード](/download/)し、[ヘルプセンター](/guide/)のおすすめに従って有効化します。
2. Ice Box のアプリ一覧で、あまり使わないけれどアンインストールはしたくないアプリにチェックを入れます。
3. Ice Box の画面下にある凍結ボタンをタップまたはスライドして、それらのアプリを凍結します。
4. 使いたいときは、Ice Box またはホーム画面のショートカットでアプリをタップします。Ice Box が解凍してから起動します。
5. [自動凍結](/guide/auto-freeze/)をオンにすると、画面オフ後に Ice Box が自動で凍結し直します。

## 注意点 {#notes}

- 凍結したアプリは、自分のプッシュ通知を受け取れません。OPPO、vivo、OnePlus などの端末では、システムのプッシュ通知を使うアプリの通知が表示されることがありますが、アプリ自体は動作しません。
- メッセージをリアルタイムで受け取る必要があるチャットアプリや、アラーム、ナビなど、常にバックグラウンドで動作している必要があるアプリは、凍結に向いていません。
- 自動凍結を使うには、Ice Box がバックグラウンドで動作している必要があります。[自動凍結](/guide/auto-freeze/)を参考に、Ice Box のバックグラウンドでの権限を設定してください。

## よくある質問 {#faq}

### 凍結と「強制停止」の違いは何ですか？

「強制停止」は、アプリの現在の動作を終了させるだけです。そのあと、ほかのイベントによってアプリが再び起動される可能性があります。凍結すると、解凍するまでアプリは動作できません。

### root 化しなくても使えますか？

使えます。Ice Box は Device Owner、ワイヤレスデバッグ、ADB、Shizuku など、root 化不要の動作モードに対応しています。[ヘルプセンター](/guide/#modes)で 3 つの質問に答えると、自分に合うモードが見つかります。

### 凍結するとアプリのデータは削除されますか？

削除されません。凍結はアプリを一時的に動作できなくするだけで、データはすべて残ります。解凍すれば、そのまま使い続けられます。
