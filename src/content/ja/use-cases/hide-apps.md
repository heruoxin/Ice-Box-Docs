## 結論 {#answer}

Ice Box で凍結しましょう。凍結したアプリはホーム画面やアプリ一覧から消え、動作もできなくなります。使いたいときは、Ice Box でタップすれば解凍して起動できます。Ice Box は指紋ロックと PIN ロックに対応しており、オンにすると Ice Box を開くときに認証が必要になり、履歴画面でも Ice Box の内容が隠れます。

## 手順 {#steps}

1. [Ice Box をダウンロード](/download/)し、[ヘルプセンター](/guide/)のおすすめに従って有効化します。
2. 隠したいアプリを Ice Box に追加して、凍結します。
3. Ice Box の設定で「Fingerprint Lock」（指紋ロック）または「PIN Lock」（PIN ロック）をオンにします。
4. 使いたいときは、Ice Box を開いて認証し、アプリをタップすると解凍して起動します。使い終わったら手動で凍結するか、[自動凍結](/guide/auto-freeze/)をオンにしてください。

## 注意点 {#notes}

- 凍結するとアプリは動作できなくなります。バックグラウンドで動作し続ける必要があるアプリを隠す方法としては向いていません。
- Ice Box 自体のアイコンは、ホーム画面に表示されたままです。
- 凍結したアプリの[ホーム画面のショートカット](/guide/shortcuts/)を作成している場合、そのショートカットはホーム画面に残ります。

## よくある質問 {#faq}

### 隠したアプリの通知は届きますか？

凍結したアプリは動作できないため、自分のプッシュ通知も受け取れません。ただし一部の端末では、システムのプッシュ通知を使うアプリの通知が表示されることがあります。その場合は、システム設定でそのアプリの通知をオフにしてください。

### 凍結したアプリは、ほかの人がシステムの設定から見られますか？

システムによって異なります。凍結したアプリは通常、ホーム画面やアプリ一覧には表示されませんが、システムのアプリ管理などの画面では見える場合があります。
