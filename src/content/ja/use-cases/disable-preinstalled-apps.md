## 結論 {#answer}

プリインストールアプリの多くはアンインストールできませんが、凍結はできます。Ice Box で凍結すると、ホーム画面やアプリ一覧から消え、バックグラウンドでも動作できなくなります。あとで必要になったら、Ice Box で解凍すれば元に戻ります。プリインストールアプリの凍結に root 化は不要で、Device Owner、ワイヤレスデバッグ、ADB などの root 化不要のモードで行えます。

## 手順 {#steps}

1. [Ice Box をダウンロード](/download/)し、[ヘルプセンター](/guide/)のおすすめに従って有効化します。
2. Ice Box のアプリ一覧をシステムアプリの表示に切り替え、使わないと確信できるプリインストールアプリにチェックを入れます。
3. それらを凍結します。以後、これらのアプリはホーム画面に表示されず、バックグラウンドでも動作しません。
4. 元に戻したいときは、Ice Box で解凍してください。

ほかのユーザーが共有した「安全に凍結できるシステムアプリのリスト」を、そのまま読み込むこともできます。Ice Box がリストのうち自分の端末で凍結できるアプリを表示し、確認したあとで凍結します。詳しくは[プリインストールアプリの凍結](/guide/system-apps/)をご覧ください。

## 注意点 {#notes}

- 使わないと確信できるアプリだけを凍結してください。重要なシステムコンポーネントを凍結すると、端末の機能に異常が起きることがあります。
- MIUI などのシステムでは、一部の重要なアプリを凍結できなかったり、再起動後にシステムによって自動で解凍されたりすることがあります。
- [QR コードで設定](/guide/qr-code/)した端末では、プリインストールアプリは初期状態ではインストールされません。必要な場合は、Ice Box の「Laboratory」で有効化できます。
- メーカーごとの詳しい状況は、[メーカー別の注意事項](/guide/devices/)をご覧ください。

## よくある質問 {#faq}

### プリインストールアプリを凍結するのと、ADB コマンドで無効化するのとでは何が違いますか？

効果は似ていますが、Ice Box には操作画面があるので、いつでも状態の確認、凍結、解凍ができ、コマンドを覚える必要はありません。

### 凍結したあとで元に戻せますか？

戻せます。Ice Box で解凍すると、アプリは元どおりになります。Ice Box をアンインストールする前に、すべてのアプリを解凍してください。

### システムアップデートのあと、凍結したプリインストールアプリは元に戻りますか？

一部のシステムは、再起動やアップデートのあとに重要なアプリを自動で解凍します。その場合は、Ice Box でもう一度凍結してください。
