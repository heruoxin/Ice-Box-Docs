## 結論 {#answer}

一般のユーザーは、Ice Box の[自動凍結](/guide/auto-freeze/)と[ホーム画面のショートカット](/guide/shortcuts/)を使えば、画面オフ時やホーム画面に戻ったときに凍結を自動で行えます。開発者は [Ice Box SDK](/developers/) を使うと、ユーザーの許可を得たうえで、自分のアプリからアプリを凍結・解凍できます。

## コードを書かずに自動化する {#no-code}

- **自動凍結**：画面オフ時、ホームボタンのタップ時やダブルタップ時に、Ice Box 内のアプリを自動で凍結します。画面オフ後の遅延時間を設定したり、充電中は除外したりできます。
- **ホーム画面のショートカット**：「Freeze All」（すべて凍結）、「Freeze + Lock Screen」（凍結して画面ロック）、「Defrost All」（すべて解凍）をホーム画面に追加して、ワンタップで実行できます。
- **凍結したアプリのショートカット**：タップすると自動で解凍して起動します。先に Ice Box を開く必要はありません。
- **「划卡冻结」**：サードパーティ製アプリの「划卡冻结」（スワイプで凍結）を使うと、履歴画面でカードをスワイプして閉じたときにアプリを凍結できます（root 化した端末のみ）。

## 開発者向け：Ice Box SDK {#sdk}

Ice Box SDK を使うと、Ice Box がインストールされて有効化されている端末で、サードパーティ製アプリに凍結と解凍の機能を提供できます：

- Ice Box の現在の動作モードと、アプリの凍結状態を照会できます。権限は不要です。
- アプリの凍結と解凍ができ、一括操作にも対応しています。ユーザーの許可が必要です。
- Device Owner モードでは、APK のサイレントインストールとアンインストールができます。
- サードパーティ製アプリが Ice Box を通じて行った操作はすべて Ice Box のログセンター（「SDK Log」）に記録され、ユーザーはいつでも確認できます。

導入方法は[開発者向け情報](/developers/)をご覧ください。

## よくある質問 {#faq}

### ほかのアプリが、知らないうちにアプリを凍結することはありますか？

サードパーティ製アプリが Ice Box を通じてアプリを凍結・解凍するには、先にあなたの許可を得る必要があります。すべての操作は Ice Box のログセンターに記録され、いつでも確認できます。
