## 結論 {#answer}

仕事用アプリを Ice Box のタブ 1 つにまとめておきましょう。退勤時にワンタップで凍結すれば、バックグラウンドで動作することも、ホーム画面に表示されることもなくなります。翌日の出勤時に、Ice Box で解凍するだけです。

## 手順 {#steps}

1. Ice Box で「仕事」タブを作成し、仕事関係のアプリを追加します。
2. 退勤するときに、「仕事」タブでそれらのアプリを凍結します。
3. 出勤したら Ice Box を開いて解凍するか、アプリの[ホーム画面のショートカット](/guide/shortcuts/)を直接タップします。Ice Box が解凍してから起動します。

## Island と組み合わせる {#island}

Island で仕事用プロファイルを作成している場合は、仕事用プロファイル内に Ice Box をインストールして、すべての機能を使えます。Island 内で Ice Box を使う場合は完全に無料です。Island の権限で Ice Box を動作させることもできます。詳しくは[その他の動作モード](/guide/other-modes/#island)をご覧ください。

## 注意点 {#notes}

- 凍結した仕事用アプリは、自分のプッシュ通知を受け取れません。仕事の連絡をいつでも受け取る必要がある場合は、凍結に向いていません。
- 一部の端末では、システムのプッシュ通知を使うアプリが、凍結後も通知を表示することがあります。

## よくある質問 {#faq}

### 時間を指定して自動で凍結できますか？

Ice Box の自動凍結は、画面オフ時、ホームボタンのタップ時やダブルタップ時に実行されるもので、スケジュールによる実行には対応していません。開発者であれば、Ice Box SDK を使って自分で実装できます。詳しくは[自動化と開発者向け連携](/use-cases/automation/)をご覧ください。

### 凍結すると仕事用アプリのデータに影響しますか？

影響しません。凍結はアプリを一時的に動作できなくするだけで、データはすべて残ります。
