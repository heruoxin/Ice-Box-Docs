Ice Box は Android 向けのアプリ凍結ツールです。あまり使わないアプリを Ice Box に入れておくと、そのアプリはバックグラウンドで動作できなくなり、ホーム画面にも表示されなくなります。使いたいときはタップするだけで、Ice Box が解凍してから起動します。

## 凍結と解凍 {#freeze}

- **凍結**：凍結したアプリは動作できず、バックグラウンドで自動起動することもなく、ホーム画面やアプリ一覧からも非表示になります。アプリ本体とデータはそのまま残ります。
- **解凍**：Ice Box でアプリをタップするか、そのアプリのホーム画面のショートカットをタップすると、Ice Box が解凍してから起動します。
- **「Freeze All」（すべて凍結）／「Defrost All」（すべて解凍）**：Ice Box の画面下にある凍結ボタンをスライドまたはタップすると、リスト内のアプリをまとめて凍結できます。「Defrost All」を使うと、すべてのアプリを一度に元に戻せます。凍結ボタンの位置とスライドの方向は、設定で変更できます。
- **「Freeze + Lock Screen」（凍結して画面ロック）**：ワンタップですべてのアプリを凍結し、すぐに画面をロックします。

動作モードに応じて、Ice Box はシステムが提供する「無効化」（disable）または「非表示」（hide）の仕組みを使ってアプリを凍結します。

## 自動凍結 {#auto-freeze}

画面オフ時、ホームボタンのタップ時、ホームボタンのダブルタップ時に、Ice Box がリスト内のアプリを自動で凍結できます。画面オフから凍結までの遅延時間（「Screen Off Delay」）を設定したり、充電中は自動凍結しないように設定したりすることもできます。詳しくは[自動凍結](/guide/auto-freeze/)をご覧ください。

## ホーム画面のショートカット {#shortcuts}

凍結したアプリのショートカットをホーム画面に作成できます。タップすると自動で解凍して起動するので、先に Ice Box を開く必要はありません。「Auto Add Shortcut」をオンにすると、アプリを凍結リストに追加したときにショートカットも自動で追加されます。詳しくは[ホーム画面のショートカット](/guide/shortcuts/)をご覧ください。

## 複数タブでの分類 {#tabs}

タブを複数作成して、「よく使う」「SNS」「ゲーム」のように用途ごとにアプリを分けて管理できます。タブの名前は変更でき、アプリをタブ間で移動することもできます。Ice Box 内のアプリは手動で並べ替えられます。

## テーマとアイコンパック {#themes}

- メイン画面のほぼすべての要素の色をカスタマイズでき、透明度も設定できます。
- Android 12 以降では、システムのダイナミックカラー（「Use system colors」）を使えます。壁紙を背景にすること（「Use wallpaper as background」）もできます。
- 昼夜のテーマ（「Day/Night Theme」）を、システムに合わせて自動で切り替えられます。
- サードパーティ製のアイコンパックに対応しており、アイコンのサイズも調整できます。
- テーマはリンクで共有したり読み込んだりできます。[共有テーマ](/themes/)で、ほかのユーザーの配色を見てみてください。

## 指紋・PIN ロック {#lock}

オンにすると、Ice Box を開くときに指紋または PIN による認証が必要になります。ロック解除には顔認証も使えます。「Fingerprint Lock」（指紋ロック）をオンにすると、履歴画面で Ice Box の内容が隠れます。

## プリインストールアプリの凍結 {#system-apps}

自分でインストールしたアプリだけでなく、一部のプリインストールのシステムアプリも凍結できます。root 化不要のモードでも同じように使えます。ほかのユーザーが共有した「安全に凍結できるシステムアプリのリスト」を読み込むこともできます。詳しくは[プリインストールアプリの凍結](/guide/system-apps/)をご覧ください。

## 新しいアプリの通知 {#new-app}

新しいアプリをインストールしたときに、Ice Box に追加するかどうかを確認するメッセージを表示できます（「Notify Add to Ice Box」）。

## オープン SDK と連携 {#sdk}

- **Ice Box SDK**：ユーザーの許可を得たほかのアプリは、Ice Box を通じてアプリを凍結・解凍できます。Device Owner モードでは、APK のサイレントインストールとアンインストールもできます。サードパーティ製アプリによる操作はすべて、Ice Box のログセンター（「SDK Log」）に記録されます。詳しくは[開発者向け情報](/developers/)をご覧ください。
- **「Configure in other Apps」（ほかのアプリで設定）**：Android の「アプリの詳細」の入口に対応しており、Greenify や AppOps などのアプリと連携できます。
- **Island**：Island の仕事用プロファイル内でも、Ice Box のすべての機能を使えます。

## バージョンと動作環境 {#requirements}

- Android 7.0 以降のスマートフォンとタブレット。
- 無料でダウンロードできます。一部の機能は Pro 版へのアップグレードが必要です。詳細はアプリ内の説明をご確認ください。
- 各バージョンの変更点は[更新履歴](/changelog/)に記載しています。
