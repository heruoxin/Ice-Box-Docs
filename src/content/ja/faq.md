## 基本的な使い方 {#basics}

### アプリを凍結するとはどういうことですか？ {#what-is-freeze}

凍結したアプリは、システムによって無効化または非表示にされます。動作できず、バックグラウンドで自動起動することもなく、ホーム画面やアプリ一覧にも表示されません。ただし、アプリ本体とデータはそのまま残っています。Ice Box で解凍すると、アプリは元どおりになります。

### 凍結とアンインストールの違いは何ですか？ {#freeze-vs-uninstall}

アンインストールすると、アプリとそのデータが削除されます。凍結はアプリを一時的に動作できなくするだけなので、データには影響せず、解凍すればそのまま使い続けられます。アンインストールできないプリインストールのシステムアプリを無効にする方法としても、凍結を使えます。

### 凍結したアプリをホーム画面に戻すには？ {#add-to-home}

Ice Box でアプリのアイコンを長押しし、「Add to Launcher」（ホーム画面に追加）を選びます。このショートカットをタップすると、Ice Box がアプリを解凍してから起動します。詳しくは[ホーム画面のショートカット](/guide/shortcuts/)をご覧ください。

### 凍結したアプリをアップデートするには？ {#update-frozen}

CoolApk（中国の Android アプリストア）を使っている場合は、CoolApk の設定の「实验室」（ラボ）で「显示隐藏应用」（非表示のアプリを表示）をオンにしてください。ほかのアプリストアを使っている場合は、先に Ice Box の設定で「Defrost All」（すべて解凍）をタップし、アップデートが終わってから再度凍結してください。

### 動作モードを切り替えたら、以前凍結したアプリを解凍できなくなった {#mode-switch}

動作モード同士には互換性がありません。Ice Box で元の動作モードに戻してください。あるモードで凍結したアプリは、同じモードで解凍する必要があります。

## Root について {#root}

### Root モードで「Failed to get ROOT permission」と表示される {#root-failed}

お使いの root 管理アプリ（Magisk など）で Ice Box の許可の記録を削除してから、もう一度 root 権限を許可してください。

### 「System Plugin」（システムプラグイン）はどうなりましたか？ {#system-plugin}

Google Play の必須要件により、System Plugin モードはバージョン 3.22.0 で削除されました。インストール済みの System Plugin は、root 権限のあるファイルマネージャーで `/system/priv-app/com.catchingnow.iceboxsystemplugin.apk` を削除し、再起動すればアンインストールが完了します。

## Device Owner モード {#device-owner}

### 通知に「このデバイスは組織によって管理されています」と表示されるのは正常ですか？ {#managed-notice}

正常です。これは Ice Box の Device Owner モードの仕組みによるものです。Device Owner の設定は、現在 root 化せずにアプリを永続的に凍結できる唯一の方法です。この文言はシステムが表示しているため削除できませんが、Ice Box の「Laboratory」にある「Organization Name」で、組織名を好きな文字に変更できます。

### 端末の設定に「Device Owner はカレンダーやメールなどの個人情報を読み取れる」と表示されます。Ice Box はそれらを読み取りますか？ {#dpm-privacy}

読み取りません。Ice Box は 2015 年から更新を続けているアプリで、Device Owner の権限で提供される機能のうち、使っているのは「アプリの凍結」などの関連する機能だけです。関係のない機能は一切使用していませんので、安心してお使いください。

### Device Owner を設定したら、システム標準のデュアルアプリやセキュリティフォルダが使えなくなった {#dual-apps}

これは一部の端末のシステム（Samsung、Xiaomi など）自体の制限です。Device Owner が有効になると、システムが一部の機能を自動でオフにするため、Ice Box では解決できません。デュアルアプリ機能がどうしても必要な場合は、次の方法を検討してください：

- Island を Device Owner に設定し、Island が提供するアプリの複製機能を使います。Ice Box は [Island モード](/guide/other-modes/#island)で動作させられます。
- Device Owner 以外の動作モードに切り替えます。ほかの動作モードは、どれもデュアルアプリに影響しません。

### アプリを解凍するたびに、権限がリセットされる {#permissions-reset}

これはシステム側の問題です。Rikka の AppOps（[Google Play](https://play.google.com/store/apps/details?id=rikka.appops)、[CoolApk](https://www.coolapk.com/)）を使うと、解凍時に権限のルールを自動で再適用できます。

### Huawei や Xiaomi の端末で、開くたびに権限を求められたり、凍結後にアプリがアンインストールされたと表示されたりする {#reinstall-prompt}

Xiaomi の端末では「MIUI 最適化」をオフにしてください。ほかの端末では、今のところ該当する設定は見つかっていません。

### 解凍したばかりのアプリが、ときどきネットに接続できない {#no-network}

一部の機種（OnePlus、Huawei など）のシステムで、まれに起こる問題です。システムが最新バージョンにアップデートされていることを確認してください。通常は、もう一度凍結してから解凍すれば直ります。

### Ice Box をアンインストールするには？ {#uninstall}

Ice Box の設定で「Uninstall」をタップします。アンインストールする前に、すべてのアプリが解凍されていることを必ず何度も確認してください。Xiaomi の端末では特にご注意ください：**ホーム画面から直接 Ice Box をアンインストールしないでください。Device Owner の権限が失われ、凍結したアプリを二度と解凍できなくなります。** 詳しくは [Ice Box のアンインストール](/guide/uninstall/)をご覧ください。

## 通知とバックグラウンド {#background}

### 凍結したアプリにもプッシュ通知が届きますか？ {#push}

OPPO、vivo、OnePlus などの端末では、システムのプッシュ通知の仕組みを使っているアプリがあり、凍結後もシステムが代わりに通知を表示します。ただし、アプリ自体がバックグラウンドで動作することはありません。これらの通知が不要な場合は、システム設定でそのアプリの通知をオフにしてください。

### 凍結したアプリでも通知を受け取りたい {#keep-push}

[MiPushFramework](https://github.com/MiPushFramework/MiPushFramework) のインストールを検討してみてください。

### Ice Box が通知を表示しているのはなぜですか？ {#ongoing-notification}

Android の要件により、バックグラウンドで動作するアプリは必ず通知を表示する必要があります。「Auto Freeze」（自動凍結）など、バックグラウンドでの動作が必要な機能をオンにすると、Ice Box は通知を 1 件表示します。この通知はシステム設定でオフにでき、機能には影響しません。自動凍結をオフにすると、Ice Box はバックグラウンドで一切動作しなくなります。

### 画面オフ後の自動凍結が効かない {#auto-freeze-fail}

端末の管理アプリや、アプリの動作を制限するアプリが、Ice Box のバックグラウンド動作を止めていないか確認してください。そのうえで、システム設定で Ice Box に「バックグラウンドでの実行」「端末のスリープ解除」などの権限を許可し、Ice Box のバッテリー使用を「最適化しない」に設定してください。Huawei の端末では、システムの制限により画面オフ時の自動凍結が効かない場合があります。その場合は、ほかの自動凍結の方法に切り替えてください。詳しくは[自動凍結](/guide/auto-freeze/)をご覧ください。

## ショートカット {#shortcuts}

### Xiaomi、Huawei、Smartisan などの端末で、ホーム画面にショートカットを追加できない {#shortcut-missing}

Xiaomi や Huawei などの端末では、システム設定で Ice Box に、ホーム画面へのショートカット追加の権限を手動で許可してください。Smartisan の端末は、どのアプリのショートカットにも対応していません。

### Xiaomi や Meizu の端末で、追加したショートカットが使えない {#shortcut-broken}

Xiaomi の端末では、システム設定で Ice Box に「関連起動」と「バックグラウンドでのポップアップ表示」の権限を許可してください。Meizu の端末では、今のところ該当するシステムの設定は見つかっていません。

### ショートカットに付く Ice Box のバッジを消すには？ {#shortcut-badge}

Android 7.0 以降では、ショートカットのバッジはシステムが付けているため、変更したり消したりすることはできません。

## その他 {#other}

### Xiaomi の音楽アプリやアプリストア、Huawei のホームアプリなど、一部のシステムアプリを凍結できない、または再起動後に勝手に解凍される {#system-unfreeze}

MIUI やほかの一部のシステムは、重要なシステムアプリを自動で解凍します。新しい EMUI では、Huawei のホームアプリは凍結できなくなりました。EMUI 9.0 より前のバージョンでは凍結できます。

### OPPO や vivo の端末で、アプリ一覧に数個のアプリしか表示されない {#app-list}

システムの権限設定で、Ice Box にアプリ一覧の読み取りを許可してください。

### Smartisan の端末で、解凍したアプリの権限がすべて「許可」になっている {#smartisan-permissions}

Smartisan のシステムの仕様で、Ice Box とは関係ありません。

### Ice Box はタブレットに対応していますか？ {#tablet}

対応しています。Ice Box には、タブレットと横画面のための専用レイアウトがあります。

### Ice Box はクリップボードを読み取りますか？ {#clipboard}

設定で「クリップボードから読み込む」をタップしたときだけ 1 回読み取り、テーマや凍結リストのリンクを探します。

### ほかにも質問がある場合は？ {#contact}

Ice Box アプリの「Feedback」からメールでお問い合わせください。その際、端末の機種名、システムのバージョン、問題のスクリーンショットをできるだけ添えてください。
