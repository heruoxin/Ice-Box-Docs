スマートフォンのシステムは、メーカーによって Android へのカスタマイズの度合いが異なるため、Ice Box の動作もメーカーごとに少しずつ違います。ここでは、わかっている注意事項をメーカー別にまとめました。設定の前に、お使いの端末のメーカーの項目に目を通しておくことをおすすめします。

## Xiaomi / Redmi / POCO {#xiaomi}

- ADB モード、ワイヤレスデバッグモード、Device Owner モードを使う前に、開発者向けオプションで「USB デバッグ（セキュリティ設定）」をオンにしてください。
- デバイスオーナーを設定する前に、「MIUI 最適化」をオフにしてください。オフにすると、アプリを凍結するたびに権限を求められたり、アプリがアンインストールされたというメッセージが表示されたりしなくなります。
- デバイスオーナーを設定すると、システム標準のデュアルアプリ機能が使えなくなることがあります。
- ホーム画面にショートカットを追加できない場合は、システムの設定で Ice Box の「ホーム画面ショートカット」関連の権限をオンにしてください。追加しても使えない場合は、Ice Box の「関連起動」と「バックグラウンドでのポップアップ表示」の権限をオンにしてください。
- MIUI 11 以降では、Ice Box と Brevent、Island、Shizuku などのアプリとの間で、権限のやり取りがうまくいかないことがあります。まず「MIUI 最適化」をオフにしてから、ホーム画面で Ice Box のアイコンを長押ししてアプリ情報を開き、権限の設定で「その他の権限」を手動でオンにしてください。
- 一部の重要なシステムアプリ（Xiaomi の音楽アプリやアプリストアなど）は、凍結できなかったり、再起動後にシステムによって自動で解凍されたりすることがあります。バージョン 3.30.7 以降の Ice Box では、MIUI / HyperOS のより多くのシステムコンポーネントを凍結できます。
- Device Owner モードを使っている場合は、**ホーム画面から Ice Box を直接アンインストールしないでください**。デバイスオーナーの権限が失われ、凍結したアプリを解凍できなくなります。[Ice Box のアンインストール](/guide/uninstall/)の手順に従ってください。

## Samsung {#samsung}

- デバイスオーナーを設定すると、セキュリティフォルダやデュアルアプリが使えなくなったり、画面ロックのパスワードがリセットされたりすることがあります。必ず先に [Samsung 端末に関する注意事項](/guide/samsung-device-owner/)をお読みください。
- Samsung ユーザーには、Root、ワイヤレスデバッグ、Shizuku、ADB のいずれかのモードをおすすめします。

## Huawei / Honor {#huawei}

- ADB モードやワイヤレスデバッグモードを使うときは、開発者向けオプションで「充電モードのみで ADB デバッグを許可」をオンにしてください。
- デバイスオーナーを設定すると、アプリを凍結するたびにアンインストールのメッセージが、解凍するたびに権限のリクエストが表示されることがあります。また、システム標準のデュアルアプリ機能が使えなくなることがあります。
- ホーム画面にショートカットを追加できない場合は、システムの設定で Ice Box にショートカット追加の権限を手動で与えてください。サードパーティ製のホームアプリを使っていると、Ice Box からショートカットを追加できないことがあります。その場合は、ホーム画面の何もないところを長押しして追加してみてください。
- システムの制限により、「Screen Off」（画面オフ時）の自動凍結が効かないことがあります。代わりに「Tap Home Button」または「Double Tap Home」で自動凍結するよう設定してください。
- 新しい EMUI では、Huawei のホームアプリは凍結できなくなりました。EMUI 9.0 以前のバージョンでは凍結できます。

## OPPO / OnePlus / realme {#oppo}

- ADB モードやワイヤレスデバッグモードを使うときは、開発者向けオプションで「権限の監視を無効化」をオンにしてください。
- デバイスオーナーを設定すると、通知領域に「デバイス管理者が有効です。タップしてオフにします」といった通知が点滅することがあります。
- アプリ一覧に少数のアプリしか表示されない場合は、システムの権限設定で Ice Box の「アプリ一覧の読み取り」権限をオンにしてください。
- システムのプッシュ通知を利用しているアプリは、凍結後もシステムが代わりに通知を表示することがあります。ただし、アプリ自体がバックグラウンドで動作することはありません。これらの通知が不要な場合は、システムの設定でそのアプリの通知をオフにしてください。
- 解凍した直後のアプリがネットワークに接続できないことがあります。アプリを閉じて開き直せば直ります。

## vivo / iQOO {#vivo}

- デバイスオーナーを設定すると、通知領域に「デバイス管理者が有効です。タップしてオフにします」といった通知が点滅することがあります。
- アプリ一覧に少数のアプリしか表示されない場合は、システムの権限設定で Ice Box の「アプリ一覧の読み取り」権限をオンにしてください。
- OPPO と同様に、一部のアプリは凍結後もシステムのプッシュ通知によって通知が表示されることがあります。

## Sony {#sony}

- デバイスオーナーを設定する前に、SIM カードを取り出してください。
- Android 9 にアップデートする前に Ice Box を設定しておくことをおすすめします。Android 9 では削除しにくい隠しアカウントが追加されたためです。すでにアップデートした場合は、[QR コードで設定](/guide/qr-code/)する方法を使えます。設定済みの端末には影響ありません。

## Meizu と Smartisan {#meizu}

- Meizu：ホーム画面にショートカットを追加しても使えないことがあります。対応するシステムの設定項目は、今のところ見つかっていません。
- Smartisan：どのアプリのショートカットにも対応していません。デバイスオーナーを設定すると、凍結時にアンインストールのメッセージが表示されることがあります。また、解凍したアプリにはすべての権限がデフォルトで許可されます。これは Smartisan のシステムの仕様で、Ice Box とは関係ありません。

## Pixel と標準の Android {#pixel}

- 標準の Android やそれに近いシステムは、各動作モードとの互換性が最も高くなっています。
- パソコンがない場合は、[QR コードで設定](/guide/qr-code/)する方法で、初期化の際に Ice Box をデバイスオーナーに設定できます。Android 11 以降なら[ワイヤレスデバッグモード](/guide/wireless-debugging/)も使えます。
