ワイヤレスデバッグモードは、root 化もパソコンも必要ありません。Ice Box はシステムの「ワイヤレス デバッグ」機能を利用して、アプリの凍結に必要な権限を取得します。すべての操作は端末だけで完了します。

使う前に、次の点をご確認ください。

- Android 11 以降のシステムが必要です。
- ペア設定の際は Wi-Fi への接続が必要です。どの Wi-Fi ネットワークでもかまいません。
- 端末を再起動したあとは、「ワイヤレス デバッグ」をもう一度オンにする必要があります。オンにしないと、Ice Box でアプリを凍結・解凍できません。

Android 10 以前のシステムを使っている場合や、パソコンで有効化したい場合は、[ADB モード](/guide/adb/)をご覧ください。

## 始める前に {#before}

Ice Box の設定画面では、次の条件を 1 つずつ確認します。満たしていない項目は、タップするとそのまま設定画面に移動できます。

1. **VPN を一時的にオフにする**。ペア設定が終わったら、またオンにしてかまいません。
2. **Ice Box の通知を許可する**。ペア設定コードは Ice Box の通知に入力します。
3. **USB デバッグをオンにする**。開発者向けオプションをまだ有効にしていない場合は、次のセクションをご覧ください。
4. **Wi-Fi に接続する**。どの Wi-Fi ネットワークでもかまいません。
5. **Ice Box のバックグラウンド実行を許可する**。一部の端末では、システムの設定で Ice Box のバックグラウンド実行を「制限なし」に変更する必要があります。

## USB デバッグをオンにする方法 {#usb-debugging}

1. 「設定」を開いて「デバイス情報」に進み、「これでデベロッパーになりました」などのメッセージが表示されるまで、「ビルド番号」を 7 回続けてタップします。
2. 「設定」に戻り、「システム」や「その他の設定」の中にある「開発者向けオプション」を開いて、「USB デバッグ」をオンにします。

メニューの場所は、メーカーやシステムのバージョンによって異なります。Ice Box のアプリ内に主なメーカーごとの手順の図解があるので、あわせてご覧ください。

## 3 ステップでペア設定コードを取得 {#pairing}

1. 開発者向けオプションで「ワイヤレス デバッグ」を探してオンにし、項目をタップして設定画面を開きます。
2. 「ペア設定コードによるデバイスのペア設定」を選びます。
3. ペア設定コードのダイアログを開いたまま通知パネルを引き下ろし、Ice Box の通知に 6 桁のペア設定コードを入力します。

ペア設定に成功すると、Ice Box に「Wireless Debugging Enabled」（ワイヤレスデバッグが有効になりました）と表示され、すぐに使えるようになります。アプリ内には動画のチュートリアルもあるので、ペア設定がうまくいかないときは展開してご覧ください。

> [!TIP]
> 開発者向けオプションに「ワイヤレス デバッグ」が見当たらない場合は、開発者向けオプションがまだ有効になっていない可能性が高いです。先に前のセクションの手順を済ませてください。

## 端末を再起動したあと {#after-reboot}

端末を再起動すると、Ice Box の権限はシステムによって取り消されます。開発者向けオプションをもう一度開いて「ワイヤレス デバッグ」をオンにすれば、Ice Box は再び動作します。オンにするよう、Ice Box が通知でお知らせします。

## よくある質問 {#faq}

### ペア設定時に「Please disable VPN and battery optimization」と表示される

Ice Box がシステムのワイヤレスデバッグのサービスに接続できていません。VPN や各種プロキシアプリをオフにし、システムの設定で Ice Box の電池の最適化をオフにしてから、もう一度お試しください。

### 「Incorrect pairing code」または「Expired, please get a new pairing code」と表示される

ペア設定コードは、ダイアログが表示されている間だけ有効です。ペア設定コードを取得し直し、ダイアログを開いたまま、できるだけ早く入力してください。

### 通知に入力欄が表示されない

Ice Box の通知が許可されているか確認してください。システムによっては通知が折りたたまれているので、通知の右側にある展開ボタンをタップすると入力欄が表示されます。

### Xiaomi、Huawei、OPPO などの端末で ADB の権限が不足していると表示される

開発者向けオプションで、メーカーごとに対応する項目をオンにしてください。Xiaomi 端末は「USB デバッグ（セキュリティ設定）」、Huawei 端末は「充電モードのみで ADB デバッグを許可」、OPPO と OnePlus の端末は「権限の監視を無効化」をオンにします。ほかのメーカーの端末でも、必要に応じて同様の項目をオンにしてください。詳しくは[メーカー別の注意事項](/guide/devices/)をご覧ください。
