凍結したアプリはホーム画面から消えます。ホーム画面から開けるようにしておきたい場合は、そのアプリ用に Ice Box のショートカットを作成できます。ショートカットをタップすると、Ice Box がまずアプリを解凍してから開きます。

## ショートカットの追加 {#add}

- Ice Box でアプリのアイコンを長押しし、「Add to Launcher」（ホーム画面に追加）を選びます。
- Ice Box の設定で「Auto Add Shortcut」をオンにすると、アプリを凍結リストに追加したときに、自動でショートカットが追加されます。
- タブのショートカットも追加できます。

## よく使う操作のショートカット {#actions}

Ice Box には、よく使う操作のショートカットもあります。ホーム画面で Ice Box のアイコンを長押しして使うか、ホーム画面に追加できます。

- **Freeze All**（すべて凍結）：Ice Box 内のすべてのアプリを凍結します。
- **Freeze + Lock Screen**（凍結して画面をロック）：凍結したあと、すぐに画面をロックします。
- **Defrost All**（すべて解凍）：Ice Box 内のすべてのアプリを解凍します。

## よくある質問 {#faq}

### ショートカットを追加できない

Xiaomi や Huawei などの端末では、システムの設定で Ice Box の「ホーム画面ショートカット」関連の権限を手動でオンにする必要があります。Smartisan の端末は、どのアプリのショートカットにも対応していません。Huawei の端末でサードパーティ製のホームアプリを使っている場合は、Ice Box から追加できないことがあります。ホーム画面の何もないところを長押しして追加してみてください。

### ショートカットを追加しても使えない

Xiaomi の端末では、システムの設定で Ice Box の「関連起動」と「バックグラウンドでのポップアップ表示」の権限をオンにしてください。Meizu の端末については、対応するシステムの設定項目がまだ見つかっていません。

### ショートカットのアイコンに付く Ice Box のバッジは消せますか？

Android 7.0 以降のシステムでは、ショートカットのバッジはシステムが付けているため、変更したり消したりすることはできません。
