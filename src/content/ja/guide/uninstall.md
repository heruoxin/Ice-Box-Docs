凍結したアプリを解凍できるのは Ice Box だけです。Ice Box をアンインストールする前に、すべてのアプリが解凍されていることを念には念を入れて確認してください。

## アンインストールの手順 {#steps}

1. Ice Box を開き、「Defrost All」（すべて解凍）で Ice Box 内のすべてのアプリを解凍します。すべてのアプリがホーム画面に再び表示されたことを確認してください。
2. Ice Box の設定を開き、「Uninstall」（アンインストール）をタップします。
3. 確認すると、Ice Box は自身のデバイスオーナーの権限を解除し（設定されている場合）、アンインストールが完了します。

> [!WARNING]
> Device Owner モードを使っている場合は、**ホーム画面から Ice Box を直接アンインストールしないでください**。Xiaomi などの端末では、デバイスオーナーの権限が失われ、凍結したアプリを二度と解凍できなくなります。

## 動作モードごとの説明 {#modes}

- **Device Owner モード**：Ice Box の設定の「Uninstall」で、デバイスオーナーの権限を解除する必要があります。解除しないと、システムがアンインストールを許可しません。
- **Root、ワイヤレスデバッグ、ADB、Shizuku の各モード**：同じく、先にすべてのアプリを解凍してから Ice Box をアンインストールしてください。
- 動作モードを切り替えたことがある場合は、凍結したときのモードに戻してから解凍してください。動作モード同士には互換性がありません。

## 解凍し忘れたままアンインストールしてしまった場合 {#already-removed}

- **Root、ワイヤレスデバッグ、ADB、Shizuku の各モード**：Ice Box をもう一度インストールし、凍結したときの動作モードに切り替えてから、アプリ一覧で凍結されたアプリを探して解凍してください。
- **Device Owner モード**：Ice Box を直接アンインストールするとデバイスオーナーの権限が失われ、凍結したアプリは解凍できなくなります。必ず上の手順どおり、Ice Box の設定からアンインストールしてください。
