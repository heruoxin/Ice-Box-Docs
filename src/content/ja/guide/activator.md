ワンクリック有効化ツールは、[@web1n](https://github.com/web1n) さんが開発した Windows パソコン用のツールです。ADB コマンドを手で入力する代わりに、このツールで Ice Box の Device Owner モードを有効化できます。

[[activator-download]]

Windows パソコンがない場合や、exe 版の有効化ツールでうまくいかない場合は、[Web 版有効化ツール](/guide/web-activator/)を使ってください。結果は同じです。

## 始める前にお読みください {#before}

中国メーカー製端末のシステムは Android に独自のカスタマイズを加えていることが多く、Device Owner モードとの互換性に問題が出ることがあります。よくある例は次のとおりです。

- Samsung 端末では、システムによってパスワードがロックされることがあります（これまでに寄せられた報告は約 20 万分の 4 の割合です）。先に [Samsung 端末に関する注意事項](/guide/samsung-device-owner/)をお読みください。
- アプリを凍結するたびにアンインストールのメッセージが、解凍するたびに権限のリクエストが表示されます（Huawei、Smartisan）。
- 通知領域に「デバイス管理者が有効です。タップしてオフにします」といった通知が点滅します（OPPO、vivo）。
- システム標準のデュアルアプリ（アプリの複製）機能が使えなくなります（Huawei、MIUI）。
- 解凍した直後のアプリがネットワークに接続できないことがあります。アプリを閉じて開き直せば直ります（OnePlus、Smartisan など）。

上記の問題を受け入れられない場合は、[ADB モード](/guide/adb/)を使ってください。こちらも root 化は不要ですが、端末を再起動するたびにパソコンで有効化し直す必要があります。

一方、Device Owner モードなら、パソコンに何度もつなぐ必要はありません。一度設定すればずっと有効で、再起動やシステムアップデートの影響も受けません。

## 手順 {#steps}

Device Owner モードで Ice Box を有効化すると決めたら、次の手順で進めてください。

1. 端末に Ice Box がインストールされていることを確認します。画面ロックは「なし」にしておきます。Sony 端末は SIM カードを取り出し、Xiaomi 端末は「USB デバッグ（セキュリティ設定）」をオンにして「MIUI 最適化」をオフにします。
2. 端末の設定で、Xiaomi アカウント、Huawei アカウント、Google アカウントなど、すべてのアカウントからログアウトします。有効化が終わったら、もう一度ログインしてかまいません。
3. 有効化ツールをダウンロードして展開します。展開先はパソコンにしてください。端末のストレージには展開しないでください。
4. 端末の USB デバッグをオンにして、USB ケーブルでパソコンに接続します。
5. 有効化ツールの「激活冰箱」（Ice Box を有効化）をクリックします。

設定が完了したら、Ice Box を開けばすぐに使えます。

ほかの問題が起きた場合は、まずシステムのアカウントがすべて削除されているか確認してください。削除しても解決しない場合は、有効化ツールに表示されたログをもとに、[Device Owner モードのよくある質問](/guide/device-owner/#faq)を参照してください。

## よくある質問 {#faq}

### 有効化ツールが読み込み中のまま進まない

有効化ツールの圧縮ファイルに含まれるファイルを、すべてパソコンに展開してから操作してください。端末のストレージには展開しないでください。また、圧縮ファイル内の exe を直接ダブルクリックしないでください。

### 有効化ツールにデバイスが見つからないと表示される

端末で USB デバッグがオンになっているか、USB ケーブルがデータ通信に対応しているか、パソコンに端末のドライバがインストールされているか、スマートフォン管理ソフトや PC 管理ソフト、ウイルス対策ソフトが接続を占有していないかを確認してください。
