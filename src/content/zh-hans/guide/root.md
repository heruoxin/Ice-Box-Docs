如果你的手机已经 Root，直接打开冰箱，在 Root 管理软件（如 Magisk）弹出的授权请求中允许冰箱即可，不需要其他设置。

Root 模式重启后依然有效，也不需要电脑。

## Root 引擎 {#engines}

冰箱提供多个 Root 引擎，包括「Root（极速）」和「Root（经典）」等，可以在「实验室」的「选择 Root 引擎」中切换。如果当前引擎在你的手机上工作不正常，可以换用其他引擎试试。

切换引擎前，请先确认所有 App 都已解冻。

## 常见问题 {#faq}

### 提示「获取 Root 权限失败」

请打开你的 Root 管理软件，删除冰箱的授权记录后，重新为冰箱授予 Root 权限。

### Root 模式下想换成别的工作模式

可以在冰箱设置的「切换工作模式」中更换。切换前请先解冻所有 App，不同模式之间互不兼容，哪种模式冻结的 App 需要在哪种模式下解冻。

### 以前的「提权插件」去哪了？

根据 Google Play 的要求，提权插件模式已在 3.22.0 版本中移除。已 Root 的手机请直接使用 Root 模式。
