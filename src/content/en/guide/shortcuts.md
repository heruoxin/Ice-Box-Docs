A frozen app disappears from the home screen. If you want to keep a way to open it there, create an Ice Box shortcut for it. When you tap the shortcut, Ice Box defrosts the app first and then opens it.

## Add a shortcut {#add}

- In Ice Box, long-press an app icon and choose "Add to Launcher".
- In Ice Box settings, you can turn on "Auto Add Shortcut" so a shortcut is added automatically when you add an app to the freeze list.
- You can also add a shortcut for a tab with "Add Shortcut".

## Shortcuts for common actions {#actions}

Ice Box also offers shortcuts for a few common actions. Long-press the Ice Box icon on the home screen to use them, or add them to the home screen:

- **Freeze All**: freezes every app in Ice Box.
- **Freeze + Lock Screen**: freezes, then locks the screen right away.
- **Defrost All**: defrosts every app in Ice Box.

## FAQ {#faq}

### Shortcuts can't be added

On Xiaomi, Huawei and some other phones, you need to manually turn on the home screen shortcut permission for Ice Box in system settings. Smartisan phones don't support shortcuts for any app. On Huawei phones with a third-party launcher, you may not be able to add shortcuts from inside Ice Box. Try long-pressing an empty area of the home screen to add them instead.

### Shortcuts were added but don't work

On Xiaomi phones, allow Ice Box to "start other apps" and to "display pop-up windows while running in the background" in system settings. On Meizu phones, we haven't found a matching system switch yet.

### Can I remove the Ice Box badge from shortcut icons?

On Android 7.0 and later, the shortcut badge is added by the system and can't be changed or removed.
