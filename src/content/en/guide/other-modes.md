A phone can only have one device owner. If you've already made another app the device owner, Ice Box can work through that app's permission directly, with no separate setup. Just choose the matching mode under "Switch Work Mode" in Ice Box settings.

## Island {#island}

For phones where Island is already set up in God Mode. Ice Box can freeze and defrost apps through Island.

You can also install Ice Box in the work profile that Island creates and use all of its features there. Using Ice Box inside Island is completely free.

To set up Island, see the [official Island setup guide](https://oasisfeng.github.io/island/setup.html).

## BlackHouse (小黑屋) {#stopapp}

If you've already made BlackHouse (小黑屋, an app by web1n) the device owner, Ice Box can use it directly as its engine.

## Brevent {#brevent}

For phones that have Brevent installed, where Brevent shows that "Disable App" is supported.

## Before you switch {#notes}

Work modes are not compatible with each other. Before switching work modes, defrost all apps in Ice Box. Apps must be defrosted in the same mode that froze them.
