> [!WARNING]
> This method requires a **factory reset**, which erases all data on the phone. Back up first. It only works on stock and near-stock Android 7.0 and later. Many systems from Chinese phone brands have removed this feature.

If you have a computer, it's better to set up with the [one-click activator](/guide/activator/) or the [web activator](/guide/web-activator/). The result is exactly the same, and no factory reset is needed.

## Setup steps {#steps}

0. Save the QR code below on another phone or a computer, or print it out, so it's ready to use.
1. Factory reset the phone.
2. On the setup screen, tap the "Welcome" text 6 or more times in a row. If nothing happens, your system has removed this feature.
3. Follow the prompts to connect to WiFi and download the QR code reader, then scan the QR code below. The phone installs and configures Ice Box automatically.

![QR code for setting up Ice Box in Device Owner mode](https://files.catchingnow.com/dpm/icebox_en.png)

## Notes {#notes}

- Once set up, it keeps working through reboots and system updates, unless the data is cleared. To uninstall Ice Box, tap "Uninstall" in Ice Box settings.
- After setting up this way, the system doesn't install pre-installed apps by default. That includes all kinds of adware, but also features such as the camera. To get pre-installed apps back, go to "Laboratory" in Ice Box settings, tap "Active Pre-installed System Apps" and choose the apps to install.
- If the phone says it needs to be reset during setup, it's usually because the network was hijacked and Ice Box failed to download.

## QR codes for other apps {#other-apps}

A phone can only have one device owner. If you want to make another app such as Island or BlackHouse (小黑屋) the device owner, scan the matching QR code below.
