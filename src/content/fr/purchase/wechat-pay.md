La dernière version d'Ice Box permet de payer avec WeChat Pay directement dans l'application. Nous vous conseillons de [télécharger et installer la dernière version](/download/) et d'acheter depuis celle-ci.

Vous pouvez aussi toujours acheter manuellement en scannant un code QR, comme avant.

## Acheter en scannant un code QR {#steps}

1. Scannez le code QR ci-dessous pour payer. **Inutile d'ajouter une note** lors du scan. Pour le scanner sur votre téléphone : enregistrez l'image, ouvrez « Scan » dans WeChat, appuyez sur le menu en haut à droite et choisissez le code QR dans vos photos.
2. **Une fois le paiement réussi**, ouvrez le compte officiel « WeChat Pay », appuyez sur « Contacter le bénéficiaire » et envoyez au vendeur le message « 冰箱激活码 » (code d'activation Ice Box). Vous n'avez pas besoin de fournir un numéro de téléphone ni une capture d'écran.
3. Un membre de l'équipe vous répondra à la main avec votre code d'activation. Si vous n'avez pas de réponse dans un délai raisonnable, écrivez au développeur avec l'option « Commentaires » de l'application Ice Box.

Une fois le code d'activation reçu, appuyez sur « J'ai déjà acheté » dans l'écran d'achat d'Ice Box et saisissez le code pour activer.

## Questions fréquentes {#faq}

### J'ai payé en scannant le code QR et utilisé Ice Box un moment, mais je n'en veux plus. Puis-je être remboursé ?

Les paiements effectués en scannant le code QR ne peuvent pas être remboursés. Si vous avez payé avec WeChat Pay directement dans l'application, vous pouvez contacter le développeur pour un remboursement avec l'option « Commentaires » de l'application.

### Quand vais-je recevoir mon code d'activation après un paiement par code QR ?

**Assurez-vous d'avoir contacté le bénéficiaire après le paiement.** Nous le répétons : ce n'est pas la même chose qu'ajouter une note lors du scan. Une fois le contact établi, le service client vous enverra votre code d'activation dès que possible. Les horaires sont de 10 h à 22 h, et il faut en général compter environ 10 minutes.

### Combien d'appareils le code d'activation peut-il activer ? Peut-il être sauvegardé ? Et si je flashe mon téléphone ?

À part les remboursements, un achat par code QR WeChat donne exactement les mêmes droits qu'un [achat Alipay](/purchase/). Consultez le guide d'achat.

### Pourquoi le développeur n'a-t-il pas répondu à mes autres questions envoyées via « Contacter le bénéficiaire » ?

Les messages WeChat sont soumis à de nombreux blocages et restrictions. Par exemple, les messages contenant le mot « 支付宝 » (Alipay) sont filtrés, si bien que le développeur ne les voit souvent pas et ne peut pas y répondre. N'utilisez pas les messages WeChat pour signaler un problème. Consultez d'abord la documentation, puis envoyez un e-mail avec l'option « Commentaires » de l'application Ice Box.

### Puis-je utiliser avec WeChat un bon de réduction obtenu sur Alipay ?

Non.

### J'ai installé Ice Box depuis Google Play. Comment l'activer avec WeChat ?

En raison des exigences strictes de Google, la version téléchargée depuis Google Play ne peut utiliser aucun autre canal pour le paiement ou la vérification.

### Une version piratée téléchargée sur Internet n'arrive pas à vérifier mon paiement ?

Nous vous conseillons de télécharger l'application officielle depuis la [page de téléchargement](/download/) de ce site.
