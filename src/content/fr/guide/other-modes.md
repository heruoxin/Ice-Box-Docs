Un téléphone ne peut avoir qu'un seul Device Owner (propriétaire de l'appareil). Si vous avez déjà défini une autre application comme Device Owner, Ice Box peut fonctionner directement grâce à l'autorisation de cette application, sans configuration séparée. Choisissez simplement le mode correspondant dans « Changer de mode de fonctionnement », dans les paramètres d'Ice Box.

## Island {#island}

Pour les téléphones où Island est déjà configuré en « God Mode ». Ice Box peut congeler et décongeler les applications via Island.

Vous pouvez aussi installer Ice Box dans le profil professionnel créé par Island et y utiliser toutes ses fonctionnalités. Utiliser Ice Box dans Island est entièrement gratuit.

Pour configurer Island, consultez le [guide de configuration officiel d'Island](https://oasisfeng.github.io/island/setup.html).

## BlackHouse (小黑屋) {#stopapp}

Si vous avez déjà défini BlackHouse (小黑屋, une application de web1n) comme Device Owner, Ice Box peut l'utiliser directement comme moteur.

## Brevent {#brevent}

Pour les téléphones où Brevent est installé et indique prendre en charge la désactivation d'applications (« Disable App »).

## Avant de changer de mode {#notes}

Les modes de fonctionnement ne sont pas compatibles entre eux. Avant de changer de mode, décongelez toutes les applications dans Ice Box. Une application doit être décongelée dans le mode qui l'a congelée.
