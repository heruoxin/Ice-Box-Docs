Une application congelée disparaît de l'écran d'accueil. Pour garder un moyen de l'ouvrir depuis l'écran d'accueil, créez-lui un raccourci Ice Box. Quand vous appuyez sur ce raccourci, Ice Box décongèle d'abord l'application, puis l'ouvre.

## Ajouter un raccourci {#add}

- Dans Ice Box, appuyez de manière prolongée sur l'icône d'une application et choisissez « Ajouter à l'écran d'accueil ».
- Dans les paramètres d'Ice Box, vous pouvez activer « Ajout auto de raccourci » : un raccourci est alors ajouté automatiquement quand vous ajoutez une application à la liste de congélation.
- Vous pouvez aussi ajouter un raccourci pour un onglet avec « Ajouter un raccourci ».

## Raccourcis pour les actions courantes {#actions}

Ice Box propose aussi des raccourcis pour quelques actions courantes. Appuyez de manière prolongée sur l'icône d'Ice Box sur l'écran d'accueil pour les utiliser, ou ajoutez-les à l'écran d'accueil :

- **Tout congeler** : congèle toutes les applications d'Ice Box.
- **Congeler + verrouiller l'écran** : congèle, puis verrouille immédiatement l'écran.
- **Tout décongeler** : décongèle toutes les applications d'Ice Box.

## FAQ {#faq}

### Impossible d'ajouter des raccourcis

Sur Xiaomi, Huawei et certains autres téléphones, vous devez activer manuellement l'autorisation de raccourcis sur l'écran d'accueil pour Ice Box dans les paramètres du système. Les téléphones Smartisan ne prennent en charge les raccourcis d'aucune application. Sur les téléphones Huawei avec un lanceur tiers, il est possible que vous ne puissiez pas ajouter de raccourcis depuis Ice Box. Essayez plutôt d'appuyer de manière prolongée sur une zone vide de l'écran d'accueil pour les ajouter.

### Les raccourcis sont ajoutés mais ne fonctionnent pas

Sur les téléphones Xiaomi, autorisez Ice Box à « démarrer d'autres applications » et à « afficher des fenêtres pop-up en arrière-plan » dans les paramètres du système. Sur les téléphones Meizu, nous n'avons pas encore trouvé l'option système correspondante.

### Puis-je retirer le badge Ice Box des icônes de raccourci ?

Sur Android 7.0 et versions ultérieures, le badge des raccourcis est ajouté par le système et ne peut être ni modifié ni retiré.
