## En bref {#answer}

Congelez l'application avec Ice Box. Une application congelée disparaît de l'écran d'accueil et du tiroir d'applications, et ne peut pas s'exécuter. Quand vous en avez besoin, appuyez dessus dans Ice Box pour la décongeler et l'ouvrir. Ice Box propose aussi un verrouillage par empreinte et code PIN : une fois activé, une vérification est demandée avant l'ouverture d'Ice Box, et le contenu d'Ice Box est masqué dans les applis récentes.

## Étapes {#steps}

1. [Téléchargez Ice Box](/download/) et activez-le en suivant la recommandation du [Centre d'aide](/guide/).
2. Ajoutez à Ice Box les applications que vous voulez masquer, puis congelez-les.
3. Activez « Verrouillage par empreinte » ou « Verrouillage par code PIN » dans les paramètres d'Ice Box.
4. Quand vous avez besoin d'une application, ouvrez Ice Box, validez la vérification, puis appuyez sur l'application pour la décongeler et l'ouvrir. Une fois terminé, congelez-la vous-même ou activez la [Congélation auto](/guide/auto-freeze/).

## À savoir {#notes}

- La congélation empêche l'application de s'exécuter. Les applications qui doivent continuer à fonctionner en arrière-plan ne se prêtent pas à ce type de masquage.
- L'icône d'Ice Box reste, elle, visible sur l'écran d'accueil.
- Si vous créez un [raccourci sur l'écran d'accueil](/guide/shortcuts/) pour une application congelée, ce raccourci reste sur l'écran d'accueil.

## Questions fréquentes {#faq}

### Les applications masquées reçoivent-elles encore des notifications ?

Une application congelée ne peut pas s'exécuter, elle ne reçoit donc pas ses propres messages push. Sur certains téléphones, les applications qui utilisent le service push du système peuvent encore afficher des notifications. Vous pouvez désactiver les notifications de cette application dans les paramètres du système.

### D'autres personnes peuvent-elles voir les applications congelées dans les paramètres du système ?

Cela dépend du système. En général, les applications congelées n'apparaissent pas sur l'écran d'accueil ni dans le tiroir d'applications, mais elles peuvent rester visibles dans certaines pages, comme la gestion des applications du système.
