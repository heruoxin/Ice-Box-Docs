Ice Box (冰箱) est un congélateur d'applications pour Android. Il congèle les applications que vous utilisez rarement : une application congelée ne peut pas tourner en arrière-plan et n'apparaît pas sur l'écran d'accueil. Quand vous en avez besoin, appuyez dessus dans Ice Box pour la décongeler et l'ouvrir.

## Ce que fait Ice Box {#what}

- Congèle et décongèle les applications en un seul appui. Les applications congelées ne peuvent pas s'exécuter et sont masquées de l'écran d'accueil.
- Congèle automatiquement quand l'écran s'éteint, ou quand vous appuyez une ou deux fois sur le bouton Accueil.
- Crée des raccourcis sur l'écran d'accueil pour les applications congelées. Un appui sur le raccourci décongèle l'application, puis l'ouvre.
- Onglets multiples, thèmes et packs d'icônes, verrouillage par empreinte et code PIN.
- Congèle certaines applications système préinstallées.
- Permet à d'autres applications de congeler et décongeler via un SDK.

Pour la liste complète, consultez [Fonctionnalités](/features/).

## Modes de fonctionnement {#modes}

Pour congeler des applications, il faut des autorisations système. Ice Box prend en charge le mode root, ainsi que des modes sans root comme Device Owner, Débogage sans fil, ADB, Shizuku et Sui. Sur les téléphones où Island ou BlackHouse (小黑屋) est déjà défini comme Device Owner, ou si vous utilisez Brevent, Ice Box peut directement emprunter leurs autorisations. Consultez le [Centre d'aide](/guide/#compare) pour voir les différences entre les modes.
