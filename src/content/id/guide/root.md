Jika ponsel Anda sudah di-root, cukup buka Ice Box dan izinkan saat pengelola root Anda (misalnya Magisk) menampilkan permintaan izin. Tidak perlu penyiapan lain.

Mode root tetap berfungsi setelah ponsel dimulai ulang, dan tidak memerlukan komputer.

## Mesin root {#engines}

Ice Box menyediakan beberapa mesin root, termasuk "Root (Tercepat)" dan "Root (Klasik)". Anda bisa beralih di antaranya lewat "Pilih mesin root" di "Laboratorium". Jika mesin yang sedang dipakai tidak berjalan dengan baik di ponsel Anda, coba mesin lain.

Sebelum mengganti mesin, pastikan semua aplikasi sudah dicairkan.

## FAQ {#faq}

### Muncul pesan "Gagal mendapatkan izin ROOT"

Buka pengelola root Anda, hapus catatan izin untuk Ice Box, lalu berikan akses root ke Ice Box lagi.

### Beralih dari mode root ke mode kerja lain

Anda bisa menggantinya lewat "Ganti mode kerja" di setelan Ice Box. Cairkan semua aplikasi sebelum beralih. Mode kerja tidak kompatibel satu sama lain, jadi aplikasi harus dicairkan dalam mode yang sama dengan saat dibekukan.

### Ke mana "Plugin sistem" yang lama?

Untuk memenuhi persyaratan Google Play, mode plugin sistem dihapus di versi 3.22.0. Di ponsel yang sudah di-root, gunakan mode root saja.
