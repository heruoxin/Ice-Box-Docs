## Ragu apakah Ice Box cocok untuk Anda? {#fit}

Ice Box sangat cocok untuk situasi ini: Anda punya beberapa aplikasi yang sesekali dibutuhkan dan tidak ingin di-uninstal, tetapi Anda tidak ingin aplikasi itu berjalan di latar belakang atau memenuhi layar utama di luar waktu itu.

Jika sebuah aplikasi harus terus bekerja di latar belakang, misalnya aplikasi chat yang harus menerima pesan secara real time, alarm, atau navigasi, aplikasi itu tidak cocok untuk dibekukan.

Siap? Pertama [pilih mode kerja](/guide/#modes), lalu [unduh Ice Box](/download/).
